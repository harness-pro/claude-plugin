# HarnessPro for Claude

Lets Claude build, test and run your [HarnessPro](https://harnesspro.ai) trading agents on Solana. It adds the HarnessPro MCP server and a skill that tells Claude how to work with it: paper first, live only when you ask.

## Claude Code

```
/plugin marketplace add harness-pro/claude-plugin
/plugin install harnesspro@harnesspro
```

Then run `/mcp`, pick `harnesspro` and sign in in your browser.

## Claude app (claude.ai, desktop)

Customize → Plugins → Add → Add marketplace, enter `harness-pro/claude-plugin`, then install HarnessPro and connect it with your HarnessPro login.

Withdrawals, raising limits and buying credits stay in the web app at https://app.harnesspro.ai.
